# 外出・外泊管理アプリ（本格導入版）

精神科病棟の入院患者の外出・外泊を記録し、帰院予定を過ぎたらiPadで知らせるアプリです。

- 使う場所：GitHub Pages のアドレス（リポジトリ名が決まり次第）をiPadのホーム画面に追加して使います。
- 位置づけ：病棟で実際に使う本番用です。旧版（gaishutsu）・試す用（gaishutsu-gaihakuA）とは別のアプリで、データの保存先も別です。同じiPadに入れても混ざりません。
- データ：iPadの中だけに保存します。外部には送りません。デモデータ（見本）を入れる機能はありません。
- 今の版：3.0.0
- 作った人：黒田 優

## ファイル
- `index.html` アプリ本体（1ファイル）
- `sw.js` `manifest.webmanifest` `icon-*.png` ホーム画面に追加して使うための部品
- `tests/` 自動テスト（`bash tests/run_tests.sh`）。テスト用の架空のデモデータは `tests/demo_data.js`
- `docs/改善メモ.md` 課題と対応の記録
- `CLAUDE.md` 開発の決まりごと

テストや画面写真のデータはすべて架空です。
